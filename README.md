# Fruchtfolgefestival – E-Mail-Signaturen

Signaturbaukasten für alle Helfenden des Fruchtfolgefestival Förderfreunde e.V.

- **Generator:** https://fruchtfolgefestival.github.io/Signatures/
- **Logo und Icons für Signaturen:** `logo-signatur.png`, `icon-web.png`, `icon-instagram.png`, `icon-facebook.png`, `icon-youtube.png` (werden von den Mailprogrammen direkt von hier geladen – bitte nicht umbenennen oder verschieben, sonst verschwinden sie in allen Signaturen)

Die Seite setzt keine Cookies und lädt nichts von Dritten. Eingaben bleiben im Browser der Nutzer:innen.

Helfer:innen dürfen ihn für ihre Festival-Signatur natürlich nutzen. Alles andere gern nach kurzer Absprache an info@fruchtfolge.live, wir sind ja nett. Details in [LICENSE](LICENSE).
